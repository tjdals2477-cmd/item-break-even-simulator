# 품목별 손익분기 시뮬레이터

단독으로 실행되는 정적 웹앱입니다. 공개 사이트에 원가, 판매가, 상품 목록은 포함하지 않습니다. Excel 파일은 브라우저에서 읽고 계산하며 서버로 업로드하지 않습니다. 입력한 값은 사용 중인 브라우저의 로컬 저장소에 저장됩니다.

## 사용법

1. **품목 입력 양식 다운로드**로 엑셀 양식을 받습니다.
2. `상품 입력` 시트에 브랜드와 품목명, 입고원가 또는 관리원가, 판매가 등 필요한 값을 입력합니다. 채널 수수료, 배송비, 광고비, 목표 이익률은 `브랜드 기본값` 시트에서 일괄 지정할 수 있습니다.
3. **품목 엑셀 불러오기**로 계산을 시작합니다. 표에서 값을 직접 바꿔 시뮬레이션할 수도 있습니다.
4. 팀원과 입력 내용을 공유하려면 **현재 설정 엑셀 저장**을 눌러 나온 파일을 전달합니다. 브라우저별 저장 값은 자동으로 동기화되지 않습니다.

회사 단가 목록은 **품목 마스터 엑셀 불러오기**로 직접 선택할 수 있습니다. 이 기능은 `고네오`와 `안트 로켓그로스` 시트만 읽으며, 각각 `디센스`와 `안트(리브인)` 품목 목록에 연결합니다. 품목 마스터는 선택한 브라우저에만 저장되고, 기존 비교표의 품목 값은 바꾸지 않습니다. 고네오 시트의 A단가가 0인 품목은 관리원가 직접 입력값 없이 등록되어 앱의 입고원가 × 1.19 규칙을 사용합니다.

엑셀의 `브랜드` 값은 `디센스`, `안트(리브인)`, `디앤앤` 중 하나를 사용합니다. `상품 입력` 시트의 1행 제목은 변경하지 마세요. 단독 HTML 파일로도 실행할 수 있지만, `xlsx.full.min.js`가 같은 폴더에 있어야 엑셀 기능이 작동합니다.

## 계산 기준

판매건수는 판매 수량 ÷ 번들 구성수량입니다. 매출은 할인 후 판매가 × 판매건수입니다. 관리원가는 직접 입력 값이 있으면 우선하며, 없으면 입고원가 × 1.19를 적용합니다. 이익은 부가세 제외 결제가에서 관리원가, 추가 변동비, 배송비, 수수료, 광고비, 기타 고정비를 차감합니다. 자세한 식은 앱 하단에 표시합니다.

`xlsx.full.min.js`는 SheetJS Community Edition 0.20.3이며, 라이선스는 `SHEETJS_LICENSE.txt`에 포함되어 있습니다.
